¿por qué es importante para un desarrollador saber usar la terminal para navegar y organizar archivos dentro de un proyecto?
La terminal es importante habilidad para uno como desarrollador permitiendo la eficiencia y el uso directo del sistema ya que permite de forma automatica ejecutar de formas repetitivas como tambien scripts complicados, como tambien comandos simples, la gestion de archivos y la organizacion de los proyectos es importante donde permite movilizarse entre directorios como tambien encontrar archivos de forma mas precisa, facilita, optimatiza el trabajo de servidores, la organizacion de los documentos o carpetas pueden ser modificados, creados, dentro de un proyecto.
